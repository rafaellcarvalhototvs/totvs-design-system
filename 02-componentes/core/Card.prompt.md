White surface container with soft, navy-tinted elevation and 16px radius — the default grouping element.

```jsx
<Card padding="md" elevation="sm">
  <h3>Indicadores</h3>
  <p>Acompanhe resultados em tempo real.</p>
</Card>
<Card interactive elevation="md">Clicável</Card>
```

`padding`: none/sm/md/lg. `elevation`: none (hairline border) / xs / sm / md / lg. `interactive` adds hover-lift. `accent` adds a thin top color bar (use rarely). Never combine a colored left-border accent — not on-brand.
